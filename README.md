# 👤 Desafio Perfil Social

## 📌 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de criar uma página de **perfil social em HTML**, apresentando informações pessoais e links para redes sociais de forma organizada e intuitiva.

## 🛠️ Tecnologias utilizadas

* HTML5

---

## 🎯 Funcionalidades

* Exibição de informações pessoais
* Inserção de foto de perfil
* Lista de links para redes sociais
* Estrutura organizada e intuitiva
* Navegação simples entre conteúdos

## 💻 Como executar

### 🔹 Opção 1: Acessar online

Acesse diretamente pelo navegador:

👉 Link disponível na seção **About** do repositório

---

### 🔹 Opção 2: Rodar localmente

1. Clone ou baixe este repositório
2. Abra o arquivo `index.html` no navegador
